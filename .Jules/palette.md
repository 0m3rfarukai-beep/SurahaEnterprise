## 2024-09-23 - Contact Form Mobile UX & A11y Optimization
**Learning:** For text inputs on mobile, specifying the exact HTML `type` attribute (like `type="email"`, `type="tel"`, `type="url"`) significantly improves mobile UX by triggering the correct software keyboard (e.g. adding '@' and '.' buttons for email, or number pads for phone). Additionally, when combining text with supplementary icons in buttons (like a 'Send' icon next to 'Submit Request' text), the icon must have `aria-hidden="true"` to prevent screen readers from announcing redundant or confusing visual information. Finally, loading states for async actions should follow the established pattern of using `Loader2` from `lucide-react` with Tailwind's `animate-spin`.
**Action:** Always apply the most semantically appropriate HTML `type` attribute to text inputs to optimize mobile data entry. When adding icons to buttons that already have descriptive text, ensure `aria-hidden="true"` is applied to the icon. Implement loading states for async buttons using the `Loader2` component convention.
