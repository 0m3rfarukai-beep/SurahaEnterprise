## 2023-10-25 - Mobile Input Optimization and Accessible Loading States
**Learning:** Adding semantically appropriate `type` attributes (e.g., `type="email"`, `type="tel"`, `type="url"`) to inputs correctly triggers optimized software keyboards on mobile devices, which significantly enhances the mobile data entry UX. Furthermore, dynamically updating submit buttons with accessible loading spinners (e.g., `<Loader2 aria-hidden="true" />`) provides immediate visual feedback during async operations without polluting screen reader announcements.
**Action:** Always verify and apply specific `type` attributes to form fields where applicable instead of leaving them as default text inputs. Implement `aria-hidden="true"` on non-informative loading and supplementary icons within interactive elements.
