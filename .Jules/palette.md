## 2024-11-07 - Semantic Input Types & Loading States in Contact Forms
**Learning:** Adding the correct semantic \`type\` attribute (\`type="email"\`, \`type="tel"\`, \`type="url"\`) to generic \`Input\` text fields significantly improves the mobile data entry UX by triggering the correct software keyboard. Additionally, providing visual feedback with a loading spinner (\`Loader2\` + \`animate-spin\`) during async form submissions, instead of relying on text alone, clarifies system status for all users, including those with visual processing differences. Furthermore, adding \`aria-hidden="true"\` to supplementary icons prevents redundant screen reader announcements.
**Action:** Always apply semantically accurate HTML \`type\` attributes to text inputs and ensure dynamic loading states include both visible text updates and accessible, visually distinct loading indicators.
