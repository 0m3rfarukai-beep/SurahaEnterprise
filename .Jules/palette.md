## 2024-06-25 - Contact Form Mobile UX & Accessibility
**Learning:** Text inputs missing specific `type` attributes fail to trigger optimized mobile keyboards (e.g., email, tel, url), creating poor mobile entry UX. Additionally, supplementary icons inside buttons (like 'Send') require `aria-hidden="true"` to prevent redundant screen reader announcements alongside the button text. Loading states for async buttons should visually replace the static icon with a spinner (like `Loader2` from `lucide-react` with `animate-spin`) to maintain the button's layout structure and provide clear feedback.
**Action:** Always apply the most semantically appropriate HTML `type` attribute to inputs. When combining text with a supplementary icon inside a button, apply `aria-hidden="true"` to the icon. Implement loading states for async actions using `Loader2` paired with the Tailwind `animate-spin` class, preserving original visual layout spacing (e.g., `ml-2` for succeeding icons).
