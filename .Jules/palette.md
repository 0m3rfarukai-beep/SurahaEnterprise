## 2024-05-24 - Mobile Keyboard Optimizations & Loading State Polish
**Learning:** This application's forms were missing specific `type` attributes (`email`, `tel`, `url`) which are critical for triggering the correct software keyboards on mobile devices. Additionally, asynchronous form submissions lacked a visual loading state on the button, leading to potential multiple submissions or user confusion. Also, icons inside buttons should have `aria-hidden="true"` to prevent redundant screen reader announcements when accompanied by text.
**Action:** When working on forms, ensure text inputs have the most semantically appropriate `type` attribute. Always implement visual feedback (like a spinning `Loader2` from `lucide-react`) during async operations. Always apply `aria-hidden="true"` to supplementary icons in buttons or labels.
