## 2024-05-17 - Accessible Form Button States
**Learning:** When indicating an asynchronous loading state in buttons, simply changing text (e.g., from "Submit" to "Sending...") is not enough. Providing visual cues like a spinner, while preserving the button width and layout, creates a smoother experience. More importantly, decorative icons inside buttons must explicitly be hidden from screen readers using `aria-hidden="true"` to prevent redundant/confusing announcements.
**Action:** When creating or modifying button states (especially for forms), always include an animated spinner (like `Loader2`) during loading states, ensure the component conditionally unmounts confusing state-specific icons (e.g. standard "Send" icon shouldn't show while loading), and verify all decorative icons possess `aria-hidden="true"`.
