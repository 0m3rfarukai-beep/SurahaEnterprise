## 2024-09-28 - Mobile Keyboard and Icon Accessibility
**Learning:** Applying the most semantically appropriate HTML `type` attribute (e.g., `type="email"`, `type="tel"`, `type="url"`) to text inputs correctly triggers optimized software keyboards on mobile devices, significantly enhancing mobile data entry UX. Additionally, when combining text with a supplementary icon inside a button or label (such as 'Submit Request' alongside a 'Send' icon), applying `aria-hidden="true"` to the icon prevents redundant or confusing screen reader announcements.
**Action:** Always verify that specific input fields like email, phone, and website URLs use their respective HTML input types rather than just `type="text"` (or omitting the type entirely, which defaults to text). Furthermore, consistently add `aria-hidden="true"` to purely decorative or supplementary icons used alongside text labels.
