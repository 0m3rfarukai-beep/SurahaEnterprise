## 2024-05-18 - Semantic HTML Types & Accessible Loading States
**Learning:** React Hook Form and Shadcn UI inputs on mobile can default to the standard text keyboard if explicit HTML types are missing, making data entry tedious. Also, supplementary icons in submit buttons (like 'Send') create redundant screen reader announcements if not hidden, and missing loading indicators (like a spinner) create confusion during async submits.
**Action:** Always apply the most semantically appropriate HTML `type` attribute (e.g., `type="email"`, `type="tel"`, `type="url"`) to text inputs to trigger optimized software keyboards. Additionally, when using icons alongside text in buttons, apply `aria-hidden="true"` to the icons, and utilize `Loader2` from `lucide-react` with `animate-spin` for clear visual feedback during loading states.
