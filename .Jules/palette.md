## 2025-02-18 - Contact Form Mobile UX & Accessibility
**Learning:** HTML input `type` attributes like `email`, `tel`, and `url` are frequently omitted on text inputs in React components, forcing mobile users to manually switch keyboards. Furthermore, decorative icons within buttons often lack `aria-hidden="true"`, leading to redundant screen reader announcements. Finally, loading states for asynchronous form submissions frequently rely on generic text like "Sending..." rather than an accessible visual indicator.
**Action:** Always verify semantic `type` attributes on `Input` components. Add `aria-hidden="true"` to supplementary icons in buttons, and ensure loading states include both semantic text updates and accessible visual spinners (like `Loader2` from `lucide-react`).
