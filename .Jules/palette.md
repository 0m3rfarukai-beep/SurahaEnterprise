## 2024-05-18 - Semantic Inputs and Mobile UX Keyboards
**Learning:** Adding specific HTML `type` attributes like `type="email"`, `type="tel"`, and `type="url"` to text inputs significantly enhances data entry UX on mobile devices by triggering optimized software keyboards (e.g. showing '@' for email or a numpad for telephone). Furthermore, using `aria-hidden="true"` on supplementary button icons next to text prevents screen readers from making redundant announcements. Finally, utilizing visual loading spinners (like `Loader2`) alongside `disabled` states prevents duplicate submissions while reassuring the user that their request is being processed.
**Action:** Always apply the most semantically appropriate HTML `type` attribute for text inputs, ensure loading states clearly indicate asynchronous network activity, and suppress screen reader announcements on purely supplementary/decorative icons with `aria-hidden="true"`.
