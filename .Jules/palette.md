## 2024-05-24 - Semantic Input Types and ARIA Labels
**Learning:** React Hook Form components with explicit visual labels often miss out on semantic `<input type="...">` enhancements, which are critical for triggering optimized virtual keyboards on mobile devices (e.g., `type="email"`, `type="tel"`, `type="url"`). Additionally, custom UI tools that rely purely on `placeholder` attributes (like the `GrowthCheckTool` here) completely lack screen reader accessibility if explicit `aria-label` attributes aren't provided.
**Action:** When auditing forms, check for correct semantic `type` mapping. If explicit labels `<label>` are missing (e.g., to keep a compact UI), ensure an `aria-label` is applied to every interactive `<input>` and `<select>` element to maintain accessibility.
