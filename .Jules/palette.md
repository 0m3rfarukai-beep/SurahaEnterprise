## 2024-06-25 - Contact Form Micro-UX Enhancements
**Learning:** Applying the correct semantic HTML `type` attributes (`type="email"`, `type="tel"`, `type="url"`) to inputs is a critical, zero-cost UX win that drastically improves mobile data entry by triggering optimized software keyboards. Additionally, pairing `aria-hidden="true"` with decorative icons inside interactive elements prevents redundant screen reader announcements, and utilizing loading spinners during async actions provides necessary visual feedback.
**Action:** Always apply the most semantically appropriate HTML `type` attribute to text inputs and ensure supplementary icons within buttons or labels are hidden from screen readers. Use standard loading patterns (like `Loader2` with `animate-spin`) for async form submissions.
