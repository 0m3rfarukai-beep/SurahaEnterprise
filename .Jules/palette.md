## 2024-09-30 - Contact Form Accessibility & Mobile UX Improvements
**Learning:** Text inputs (`<Input>`) in contact forms often default to `type="text"`, bypassing optimized software keyboards on mobile devices for specific data types like email, phone numbers, and URLs. Additionally, dynamic submission buttons often combine loading text with icons but fail to hide the icons from screen readers, leading to redundant or confusing announcements.
**Action:** When working with form components (like `ContactForm.jsx`), always explicitly apply the most semantically correct HTML `type` attribute (e.g., `type="email"`, `type="tel"`, `type="url"`) to corresponding inputs to ensure the correct mobile keyboard is triggered. Furthermore, when adding supplementary or loading icons (such as `Loader2` or `Send`) alongside button text, apply `aria-hidden="true"` to the icons to maintain a clean screen reader experience.
