## 2024-05-19 - Accessible Form Inputs & Loading States
**Learning:** Adding `aria-hidden="true"` to supplementary UI icons (such as those alongside button text) prevents redundant and confusing screen reader announcements. Using semantic HTML `type` attributes like `email`, `tel`, and `url` instead of plain text inputs ensures mobile software keyboards adapt properly, greatly enhancing user data entry. Finally, indicating a loading state with `Loader2` combined with a `disabled` attribute informs the user of async progress while preventing duplicate submissions.
**Action:** Apply `aria-hidden="true"` to supplementary icons in buttons/labels, always use appropriate HTML `type` attributes for text inputs, and provide visible feedback during asynchronous actions such as form submissions across all future form components.
