## 2024-07-04 - Improve button accessibility by hiding decorative icons from screen readers
**Learning:** Found several buttons (like "Submit Request", "Request Exact Quote", "Send My Recommendation") combining text with a supplementary icon (`<Send>`, `<ArrowRight>`). Screen readers will read the button text, but unless `aria-hidden="true"` is applied to the decorative icon, it can create confusing/redundant announcements or clutter. Also found loading states on forms could be improved using the standard `Loader2` from `lucide-react` with `animate-spin` class per project convention.
**Action:** When combining text with a supplementary icon inside a button or label, apply `aria-hidden="true"` to the icon to prevent redundant or confusing screen reader announcements. Use `Loader2` combined with `animate-spin` for async loading actions to provide standard visual feedback.
