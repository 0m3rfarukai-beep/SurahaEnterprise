## 2024-05-24 - Semantic Input Types for Mobile UX
**Learning:** Using appropriate semantic HTML `type` attributes (like `type="email"`, `type="tel"`, and `type="url"`) for form inputs is critical for accessibility and user experience, particularly on mobile devices where they trigger optimized software keyboards.
**Action:** Always apply the most semantically appropriate `type` attribute to text inputs in forms to enhance mobile data entry UX and ensure screen readers announce the expected input format correctly.
