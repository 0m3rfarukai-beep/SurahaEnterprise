## 2024-06-12 - Enhance Mobile Input UX and Accessible Loading States
**Learning:** Adding explicit semantic HTML `type` attributes (e.g., `type="email"`, `type="tel"`, `type="url"`) to inputs correctly triggers optimized software keyboards on mobile devices, vastly improving data entry UX. Additionally, combining supplementary visual icons (like 'Send' or loading spinners) with descriptive text inside a button requires applying `aria-hidden="true"` to the icons to prevent confusing and redundant announcements by screen readers.
**Action:** Always apply the most semantically appropriate `type` attribute for text inputs. When placing decorative or supplementary icons next to text in interactive elements, consistently apply `aria-hidden="true"` to the icons and implement `Loader2` with `animate-spin` for async loading states.
