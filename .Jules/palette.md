## 2024-05-21 - Added Loader2 spinning animation to ContactForm submit button
**Learning:** Adding a spinning loader icon to async submit buttons provides much clearer feedback to the user that their request is being processed. The "Sending..." text helps, but standard interaction design (and this repos design language with lucide-react) works best when an icon animates to denote work happening.
**Action:** Next time, always check if async forms display a clear animated loading state during submission.
